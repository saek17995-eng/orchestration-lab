# 三维智能管弦乐配器教学系统

面向作曲、配器与音乐科技教学的浏览器端交互原型。系统以三维舞台、真实 MusicXML 音符时间线和可解释规则分析，展示不同乐器组在配器中的层次、平衡与音区关系。

## 已实现

- Three.js 三维管弦乐舞台，可旋转、缩放并点击乐器席位
- 真实解析未压缩的 `.musicxml` / `.xml` 文件，读取作品、声部、小节、速度、拍号、音高、时值、力度和基础演奏法
- MusicXML 音符事件统一驱动小节时间线、三维席位发光与当前织体显示
- Web Audio 合成音源，按乐器组生成不同音色并支持声像、音量、独奏、静音、变速和跳转
- 内置 8 小节、5 声部 MusicXML 教学示例，可直接体验完整流程
- 木管、铜管、打击乐、弦乐分组独奏与静音
- 15 种乐器的音域、移调、音色和演奏法知识卡
- 基于当前真实音符的织体密度、力度平衡和典型配器风险提示
- 文字指令：播放、暂停、跳转小节、调速、独奏、静音和分析
- WebMCP 工具：读取状态、跳转小节、控制播放和独奏乐器组

## 本地运行

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址即可使用。

## 构建

```bash
pnpm build
```

## 当前边界

当前版本是可操作的教学原型。已支持未压缩 MusicXML 的真实音符映射和浏览器合成音，但暂不支持压缩 `.mxl`、MIDI、采样级管弦乐音源，以及连音线合并、复杂速度曲线等高级谱面语义。语音识别和方案 A/B 数据对比也留待下一阶段实现，界面会明确提示尚未支持的格式与能力。
