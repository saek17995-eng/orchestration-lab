# 三维智能管弦乐配器教学系统

面向作曲、配器与音乐科技教学的浏览器端交互原型。系统以三维舞台、示例总谱时间线和可解释规则分析，展示不同乐器组在配器中的层次、平衡与音区关系。

## 已实现

- Three.js 三维管弦乐舞台，可旋转、缩放并点击乐器席位
- 32 小节内置教学示例，播放时乐器与总谱同步高亮
- 木管、铜管、打击乐、弦乐分组独奏与静音
- 15 种乐器的音域、移调、音色和演奏法知识卡
- 织体密度、力度平衡和典型配器风险提示
- 文字指令：播放、暂停、跳转小节、调速、独奏、静音和分析
- MusicXML 元数据读取，以及 MXL/MIDI 文件接收状态
- WebMCP 工具：读取状态、跳转小节、控制播放和独奏乐器组

## 本地运行

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址即可使用。

## 构建

```bash
pnpm build
```

## 当前边界

当前版本是可操作的教学原型。导入 MusicXML 时会读取作品标题，但音符事件仍使用内置示例驱动。真实 MusicXML/MIDI 音符映射、采样音源、语音识别和方案 A/B 数据对比留待下一阶段实现，界面不会把这些能力伪装成已完成。
