# 三维智能管弦乐配器教学系统

面向作曲、配器与音乐科技教学的浏览器端交互原型。系统以写实分层三维舞台、MusicXML/MXL/MIDI 统一音符时间线和可解释规则分析，展示不同乐器组在配器中的层次、平衡与音区关系。

## 已实现

- Three.js 分层扇形管弦乐舞台，包含指挥、谱架、独立乐器造型和弦乐/木管/铜管/打击乐分区
- 精确编制：第一小提琴10人、第二小提琴8人、中提琴6人、大提琴6人、低音提琴4人；木管2/2/2/2；铜管圆号4、小号2、长号3、大号1
- 五类弦乐使用由浅至深的紫色色阶，每位演奏员持有与声部对应的可发光三维乐器模型
- 当前发声音符会驱动对应乐器的所有席位与地面区域脉冲发光
- 真实解析 `.musicxml`、`.xml`、压缩 `.mxl`、`.mid` 与 `.midi` 文件
- 解析作品、声部、小节、可变速度、拍号、音高、时值、力度、移调、和弦及复调时间轴
- 合并跨小节连音线，并读取圆滑线、断奏、保持音、重音、延长记号及常见装饰音语义
- 专业采样模式按乐器加载 MusyngKite SoundFont，并提供离线 Web Audio 合成回退
- 支持声像、音量、独奏、静音、变速和小节跳转
- 内置 8 小节、5 声部 MusicXML 教学示例，可直接体验完整流程
- 木管、铜管、打击乐、弦乐分组独奏与静音
- 15 种乐器的音域、移调、音色和演奏法知识卡
- 基于当前真实音符的织体密度、力度平衡和典型配器风险提示
- 文字指令：播放、暂停、跳转小节、调速、独奏、静音和分析
- WebMCP 工具：读取状态、跳转小节、控制播放和独奏乐器组

## 本地运行

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址即可使用。

## 构建

```bash
pnpm build
```

## 当前边界

当前版本是可操作的教学原型。SoundFont 采样需要网络并会在首次播放时加载，失败时自动回退到合成音源；商业音色库不会随网页分发。复杂制谱能力中，跨音连线的连续相位、发夹渐强曲线、微分音、任意反复/跳房子结构及 MusicXML `score-timewise` 尚未完整模拟。语音识别和方案 A/B 数据对比留待下一阶段实现。
